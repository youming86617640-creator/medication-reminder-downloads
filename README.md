# 服药提醒

适用于 Android 的本地服药记录与提醒工具。

[下载最新安装包](https://github.com/youming86617640-creator/mama-meds-downloads/releases/latest/download/mama-meds.apk)

## 功能

- 为多种药品分别设置每天次数和服药间隔。
- 记录实际服药时间，根据上一次实际时间计算下一次提醒。
- 每天独立开始，药品设置长期保留。
- 支持补上记录、修改时间和撤销误点。
- 可调整响铃时长、铃声大小，并检查新版本。

## 安装与更新

下载 APK 后按手机提示安装。已有版本请覆盖安装，无需卸载。

0.3.8 及之后版本可在“设置 → 检查更新”中检查新版。

## 数据与使用

药品和服药记录保存在手机本地；联网仅用于检查版本，下载由系统浏览器处理。不提供药名、用量或服药间隔建议。

本仓库仅分发安装包和更新说明，不包含完整源码或个人服药记录。
